# AI Chat Log

## Project
WNBA Gender Inequality and Working Conditions (2023–2025)

## AI Tool Used
ChatGPT (OpenAI)

## How AI Was Used
ChatGPT was primarily used as a brainstorming and review tool throughout the project.

It assisted with:
- Brainstorming possible research topics related to gender inequality in professional basketball.
- Narrowing the project focus to labor and media inequality in the WNBA.
- Discussing ways to approach the research question and organize the project.
- Reviewing project descriptions and README documentation for clarity.
- Providing feedback on the organization and presentation of the dataset.
- Offering occasional troubleshooting guidance when working with GitHub and JSON formatting.

## Independent Work
I independently researched and selected the sources included in the dataset, reviewed the source material, made decisions about which records to include, and entered and organized the data.

ChatGPT was used to help develop ideas and review portions of the work, but the research, source selection, and final project decisions were my responsibility.
